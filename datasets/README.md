# datasets/

Benchmark fixtures, split and labeled. Generated by
`scripts/generate_dataset.py` (deterministic; `--check` verifies committed
equality).

- `held_out/held-out-cases.jsonl` — 111 held-out cases: price 41, saas_pricing
  35, product_change 35, including 12 edge cases. This split is the evaluation
  set for the release gates and is never used for tuning.
- `dev/dev-cases.jsonl` — 15 development/tuning cases (5 per detector). Never
  counted toward held-out minimums.
- `labeling-rubric.md`-equivalent policy lives in
  `docs/provenance-and-labeling.md`.

## Provenance

Every case records `provenance` and `provenance_detail`:

- `synthetic` — authored fictional page content (Acme Analytics is invented).
- `derived` — structural patterns observed on public vendor pricing pages
  (vercel.com/pricing, linear.app/pricing, notion.com/pricing, retrieved
  2026-09-23, HTTP 200); only the pattern informed the fixture, no page copy,
  prices, names or proprietary content is redistributed (recorded per case).
- `real_public` — supported value; no permissively licensed real captures are
  included in this revision.

No private or customer content is used anywhere.

## Labeling status

All labels are rubric-driven drafts by one labeler
(`rubric-labeled-draft (ai-author: hermes/jack-dev)`) against
`docs/provenance-and-labeling.md`, with
`labeling.review_status = "pending-independent-review"`. They are **not**
independently human-adjudicated yet; the runner and the blocked artifact
record that as a launch blocker. Values in every fixture are static fixtures,
not real Jev outputs.

## Schema

Each line validates against `schemas/fixture-case.schema.json`; the CLI
enforces this plus held-out minimums (>=100 total, >=30 per detector, >=10
edge cases), duplicate-id detection and provenance completeness.
